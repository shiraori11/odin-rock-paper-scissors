#### Reflection:
I found myself having a trouble in getting the logic right. This is because I didn't write down the logic on paper so it might look right when I thought about it but when executed it will return a unexpected result. I struggled on the logic of asking the user a choice and having the computer choose randomly per round. What happened is that the choices for round one would be the result of the remaining rounds.

This is why writing down the program logic in plain english, even as a comment is important to debug your program even if you haven't started coding it yet.
